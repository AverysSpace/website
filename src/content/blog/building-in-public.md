This site is a central place for my software projects, releases, and development notes.

I want the site to make it easy to find the source code, understand what each project does, and follow along as things change.

## What you'll find here

- Project pages with links to their repositories.
- Release information linked to the projects' official GitHub releases.
- Notes about experiments, development, and things I've learned.

The site will evolve alongside the projects. For the latest implementation details, the linked repositories remain the source of truth.
